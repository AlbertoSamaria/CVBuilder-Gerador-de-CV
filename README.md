# CVBuilder — Gerador de Currículos Online

Gerador de currículos moderno, responsivo e 100% estático.

## Funcionalidades

- Formulário completo para dados pessoais
- Foto de perfil
- Perfil profissional
- Experiência profissional
- Formação académica
- Competências técnicas e pessoais
- Idiomas
- Certificações
- Projetos / portfólio
- 3 modelos: Moderno, Clássico e Minimalista
- Pré-visualização em tempo real
- Guardar e carregar no navegador usando localStorage
- Exportação para PDF através da impressão do navegador
- Responsivo para computador, tablet e telemóvel
- Sem PHP, MySQL ou servidor backend
- Sem dependências externas

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `cvbuilder`.
2. Envie todos os ficheiros deste projeto para a raiz do repositório.
3. No GitHub, abra `Settings > Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha `main` e a pasta `/ (root)`.
6. Guarde.
7. O GitHub vai gerar o endereço do site.

## Privacidade

Os dados são processados no navegador. O projeto não envia os dados do currículo para um servidor.
